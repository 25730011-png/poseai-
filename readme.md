# PoseAi

웹캠으로 보는 나의 체형, 진단부터 교정까지
AI 체형 진단 및 모니터링 서비스

## 소개
설치·가입·별도 장비 없이 휴대폰 카메라와 브라우저만으로 거북목·어깨 수평·골반 수평 3가지를 측정하고,
날짜별 기록과 교정 가이드까지 한 흐름으로 제공하는 모바일 웹서비스입니다.
점수나 양호/주의 판정 대신 지금 상태 설명과 지난번 대비 변화를 보여 주고,
측정은 1~2주에 한 번, 매일은 스트레칭 체크로 자세 습관을 관리해요.

- 영상·사진은 저장·전송하지 않고 브라우저 안에서만 처리
- 의학적 진단이 아닌 참고용 분석

## 화면 구성
index.html 하나에 화면을 section으로 나눠 넣고, 주소 끝 #이름으로 전환해요. 기능은 모두 js/app.js에 있어요.

| 주소 | 화면 | 내용 |
|---|---|---|
| #home | 메인 | 서비스 소개, 진행 순서, 측정 항목, 바로가기 |
| #measure | 촬영·측정 | 정면·측면 각 5초 측정 |
| #report | 체형 리포트 | 오늘의 자세 요약, 항목별 각도·상태 설명, 지난번 대비 변화, 같이 나타난 자세 패턴, 기록 저장 |
| #history | 기록·그래프 | 변화 그래프, 스트레칭 달력, 날짜별 기록 |
| #guide | 교정 가이드 | 불편한 부위 체크, 맞춤 스트레칭·오늘 했어요 체크, 병원 찾기 |
| #focus | 공부 타이머 | 공부하는 동안 자세 지켜보기, 목이 나오면 알림, 공부 기록 |
| #faq | FAQ · AI 자세 코치 | 자주 묻는 질문, AI 코치(Gemini) |
| #settings | 설정 | 예시 데이터 켜기/끄기, 다시 측정 주기(1주/2주), 알림 소리, 기록 지우기 |
| #login, #signup | 로그인·회원가입 (선택) | 기록 동기화용 |

## 사용 기술
- HTML, CSS, JavaScript
- MediaPipe Pose (웹캠 자세 인식)
- LocalStorage (기록 저장), Chart.js (변화 그래프)
- 건강보험심사평가원 병원정보서비스 오픈API (인증키는 Cloudflare Workers 중계 서버에만 보관)
- GitHub Pages 배포

## 로그인 + 기록 저장 (Firebase, 11/10)
- 회원가입: 아이디 + 닉네임 + 비밀번호 / 로그인: 아이디 + 비밀번호
- Firebase Authentication(이메일/비밀번호) 사용. 아이디는 안에서 아이디@poseai.app 으로 처리
- Firestore: users/{uid} (아이디·닉네임), users/{uid}/records/{저장 시각} (측정 기록)
- 보안 규칙: 로그인한 본인만 자기 데이터 읽기·쓰기 (pages/firebase-rules.txt)
- js/app.js 의 firebaseConfig 에 Firebase 웹 앱 설정값을 넣으면 연결됨
- 처음엔 구글 시트(Apps Script)로 만들었다가, 비밀번호가 없고 누구나 조회할 수 있는 보안 문제 때문에 Firebase로 바꿈
- 기록 화면에 "공부 중 자세(최근 7일)" 요약 추가: 공부 타이머 결과(바른 자세 비율·횟수·총 시간·알림 수)를 측정 그래프·스트레칭 달력과 함께 보여 줌 → 진단(측정) · 교정(스트레칭) · 예방(공부 타이머)이 한 화면에 모임
